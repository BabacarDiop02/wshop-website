Glossaire du digital pour PME

Les mots techniques qu'on vous jette parfois à la figure, expliqués simplement.

API
Interface qui permet à deux logiciels d'échanger des informations automatiquement — par exemple, votre site qui interroge le système de paiement Wave pour confirmer une transaction.
Backend
La partie invisible d'une application : le serveur, la base de données et la logique qui traitent les informations en coulisses.
Frontend
La partie visible d'un site ou d'une application, ce que l'utilisateur voit et avec quoi il interagit directement.
Responsive (design)
Un site "responsive" s'adapte automatiquement à la taille de l'écran : ordinateur, tablette ou smartphone.
SEO / Référencement
Ensemble de techniques pour améliorer la position d'un site dans les résultats de recherche Google, sans payer de publicité.
Hébergement
Le serveur où sont stockés les fichiers de votre site pour qu'il soit accessible sur internet en permanence.
Nom de domaine
L'adresse de votre site (par exemple, votreentreprise.sn), à louer chaque année auprès d'un registraire.
Certificat SSL / HTTPS
Un système qui chiffre les données échangées entre le visiteur et votre site (cadenas dans la barre d'adresse), indispensable pour la confiance et le référencement.
CMS
Un logiciel qui permet de gérer le contenu d'un site (textes, images) sans compétences techniques, une fois le site livré.
PWA (Progressive Web App)
Un site web qui peut être "installé" comme une application sur un téléphone, avec un fonctionnement partiel hors-ligne.
Passerelle de paiement
Le service (Wave, Orange Money, carte bancaire) qui permet à vos clients de payer directement en ligne en toute sécurité.
UX (expérience utilisateur)
Tout ce qui rend un site agréable et simple à utiliser : navigation claire, temps de chargement rapide, parcours logique.
MVP
« Produit minimum viable » : la version la plus simple d'une application, permettant de tester une idée rapidement avant d'investir davantage.
Maintenance
Le suivi régulier d'un site après sa mise en ligne : mises à jour de sécurité, corrections de bugs, petites évolutions.
